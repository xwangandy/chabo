| :--- | :--- | :--- | :--- | :--- |
| **1. 频道质量与含金量评分** | **能（Day 1 可用）** | 仅需频道近 10～20 条帖子的公开浏览量快照 + 站内探针 | **确定性启发式公式（L0）**：基于阅读率稳定性、浏览曲线形态、探针点击率打分 | 引入历史广告实测有效点击率（CTR）与留存率动态校准权重 |
| **2. 广告目标与频道类目匹配** | **能（Day 1 可用）** | 0 历史订单（靠人工/运营打标签） | **布尔硬过滤 + 类目亲和度矩阵（L0）**：例如推广“AI工具”优先匹配 `ai / software / tools` 频道，剔除禁投类目 | 基于历史同品类在不同频道类目的实测转化表现更新亲和度矩阵 |

| **4. 多频道预算组合优化** | **能（按规则分摊）** | 0 历史订单即可做“风险分散配比” | **80/20 赛马配比规则**：80% 预算分给评分高、价格适中的主力号，20% 分给待测潜力号 | 基于带约束的组合优化（在总预算与单频道频控上限下，最大化预期有效点击数） |
| **5. 新频道冷启动与探索预算** | **能（Day 1 可用）** | 新频道入驻即触发 | 先挂免费「日常探针按钮」跑 7 天测出基础活人率；或在联投套餐中强制搭售 10%～15% 探索预算 | **Thompson Sampling（汤普森采样 / 多臂老虎机）**：根据不确定性自动分配探索流量 |
| **6. 素材与发布时间 A/B 测试** | **仅支持粗粒度同场赛马** | 单组素材至少需要 **30～50 次有效点击** 才能检验出显著差异 | 不做同频道同日连发两条（会激怒读者），改为**「交叉轮转赛马」**（如 A 素材投频道 1/2，B 素材投同量级的频道 3/4） | 跨场次积累显著性检验（双比例 Z 检验或贝叶斯胜率概率计算） |

## 二、 现有 `ChaBo` 评分代码的缺陷审计与重构方案（调研项 3 & 8）

### 1. 现有代码 `PricingService.assess_channel`（`src/chabo/services/channel.py` 第 1102～1247 行）审计 【源码事实】
我们在检查现有代码时发现，当前的频道评估逻辑是：
```python
interaction_bps = self._interaction_bps(light_unique_clickers_30d, estimated_reach) # 6000 ~ 14000
history_bps = 10000 + min(repeat_purchase_count, 5) * 500 - min(dispute_count, 5) * 1200
risk_bps = {"normal": 10000, "watch": 7500, "high": 4500, "blocked": 0}[risk_level]
score = int((interaction_bps * 0.4 + history_bps * 0.3 + risk_bps * 0.3) / 100) # 截断在 0~100
```
* **存在的三大数学与业务缺陷**：
  1. **分数虚高膨胀（通货膨胀）**：如我们在 `chabo.sqlite3` 实测看到的那样，3 个演示频道算出来的 `score` **全都是 `100` 分（满分）**！因为只要 `interaction_bps >= 12000`、`history_bps >= 10500`、`risk_bps == 10000`，加权除以 100 就会超过 100 并被 `min(100, score)` 截断成 100 分。所有频道都是 100 分，评分就彻底失去了区分度！
  2. **缺少“置信度（Confidence）”与样本量惩罚**：一个刚发了 1 条帖子的频道和一个稳定运营了 1 年的频道，只要单次点击率一样，算出来的分数居然一模一样。
  3. **缺少“刷量异常信号（Anti-Fraud Signals）”自动扣分**：当前 `risk_level` 全靠人工手填（`normal/watch/high`），没有根据“浏览量暴增异常”、“探针点击但 0 二跳”等客观数据自动降级。

### 2. 优化后的「三维可解释频道评分模型（AdLab Channel Score v2）」

我们将每个频道的评价拆解为三个独立且透明的指标：**① 综合质量分 $S \in [0, 100]$**、**② 数据置信度 $C \in [0\%, 100\%]$**、**③ 异常风险灯（绿/黄/红）**。

#### （1）综合质量分 $S$ 的四个可解释子维度（满分 100 分，杜绝满分膨胀）
$$S = 0.30 \times Q_{\text{reach}} + 0.35 \times Q_{\text{intent}} + 0.20 \times Q_{\text{stability}} + 0.15 \times Q_{\text{fulfill}}$$

* **$Q_{\text{reach}}$（有效阅读健康度，0～100）**：
  - 计算 `ERR_24h = median_24h_views / subscribers`。
  - 正常优质中文频道的 `ERR_24h` 通常在 **8%～35%** 之间（得 60～95 分）；若 `< 3%` 说明死粉过多（得 <40 分）；若 `> 80%` 且无外部大号转发，反而触发**刷量嫌疑降权**！
* **$Q_{\text{intent}}$（脱水活人点击力，0～100 · 核心权重 35%）**：
  - 优先采用平台实测的**脱水有效点击率（`filtered_clicks / message_views_24h`）**或**站内探针去重触发率（`probe_unique_clicks / message_views_24h`）**。
  - 引入**贝叶斯平滑（Bayesian Smoothing）**解决小样本波动：
    $$\widehat{\text{CTR}}_i = \frac{k \cdot \overline{\text{CTR}}_{\text{category}} + \sum \text{Clicks}_i}{k + \sum \text{Views}_i}$$
    其中 $\overline{\text{CTR}}_{\text{category}}$ 为同品类先验平均点击率（如 `0.5%`），平滑常数 $k = 10,000$ 浏览量。这样，一个没跑过几次的新频道不会因为偶然多点了几下就飙到满分，也不会因为 0 历史而被判死刑。
* **$Q_{\text{stability}}$（更新与阅读波动稳定性，0～100）**：
  - 考察近 10 条帖子的 24h 浏览量变异系数 $\text{CV} = \sigma / \mu$。正常频道每篇阅读量相对稳定（$\text{CV} < 0.5$）；按单买假量的频道往往平时每篇只有 200 阅读，一发广告突然跳到 10,000 阅读（$\text{CV} > 1.5$，直接扣分并亮黄灯）。
* **$Q_{\text{fulfill}}$（履约守信度，0～100）**：
  - 初始基准 80 分；每准时无争议完成 1 单 +2 分（封顶 100 分）；每发生 1 次私自提前删帖、取消置顶或权限掉线导致发布失败，直接扣 25 分！

#### （2）数据置信度 $C$（告诉广告主“这个分数有多靠谱”）
* **高置信（High, $C \ge 80\%$）**：已在平台完成 $\ge 5$ 次真实投放或累计 $\ge 14$ 天探针采样，且具备 24h 浏览量自动快照权限。
* **中置信（Medium, $40\% \le C < 80\%$）**：已完成 1～4 次投放或 3～13 天探针采样。
* **低置信 / 待验证（Low / Cold-Start, $C < 40\%$）**：新接入频道，仅有基础订阅数和静态浏览中位数，报表上显式标注 **「🌱 新号测试期（建议小额试投）」**。

## 三、 四种技术路线在各阶段的适用性对比（拒绝过度设计）

| 技术方案 | 原理简述 | 优点 | 缺点与合规风险 | 插播采用阶段 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 确定性规则引擎**<br/>（Rule-Based） | 硬过滤条件 + 明确权重的加权打分 + 红黑榜阈值淘汰 | **0 样本启动、100% 可解释、0 算力成本、100% 符合 Telegram 条款** | 权重由人工设定，无法自动捕捉复杂的非线性交互特征 | **V1 核心主力（M1～M5 必上）** |
| **2. 统计推断模型**<br/>（贝叶斯平滑 / 多臂老虎机 MAB） | 用先验分布处理小样本不确定性，生成区间估计 `[CPC_low, CPC_high]` 与探索分配 | **极适合 10～200 单的小样本期**，不会给出荒谬的极端预测，天然支持新频道冷启动探索 | 需要确保输入指标已做过防刷清洗 | **V1.5 进阶核心（M4～M6 接入）** |
| **3. 传统机器学习**<br/>（GBDT / 逻辑回归 CTR 预估） | 基于用户-频道-素材交叉特征训练点击率预测模型 | 在海量样本（数万次曝光点击）下预测精度高 | **小样本下极易过拟合**；且若使用 Telegram 平台数据训练模型，直接触碰 **Telegram API Terms 1.5 违约红线**！ | **V1 坚决不做（P2 远期再议）** |
| **4. 大语言模型**<br/>（LLM 辅助生成与解读） | 仅针对广告主自填表单生成多版本文案，或将规则引擎算好的结构化报表翻译成自然语言复盘摘要 | 极大节省运营写文案和写结案总结的时间，客户体验好 | 存在幻觉风险（可能编造数字）；严禁直接赋予其改库/发帖/扣款权限 | **V1 辅助生产力工具（仅限处理第一方表单与脱敏汇总指标）** |

## 四、 多频道预算分配与复投优化的落地算法（V1 可直接编码）

当广告主拿出预算 $B$（例如 \$300），希望推广某类目产品时，系统按以下 4 步生成可解释方案：

1. **Step 1 资格硬过滤（Hard Filter）**：
   - 筛出满足：`status == 'active'`、`bot_can_post == True`、未将广告主所属类目列入禁投名单、期望排期日尚未达到 `daily_ad_limit`、单帖报价 $\le 0.5 B$ 的候选频道集合 $\mathcal{C}$。
2. **Step 2 性价比排序（Expected Efficiency Ranking）**：
   - 对每个候选频道 $i \in \mathcal{C}$，计算预期单次有效点击成本（Expected CPC）：
     $$\mathbb{E}[\text{CPC}_i] = \frac{\text{Price}_i}{\text{MedianViews}_{24h, i} \times \widehat{\text{CTR}}_i \times \text{CategoryMatch}_i}$$
   - 同时输出置信区间（基于历史方差或泊松分布置信带），例如：`预计有效点击 45～80 次，预计 CPC $0.35～$0.62（置信度：中）`。
3. **Step 3 组合配比（80% 主力 + 20% 赛马探索）**：
   - 贪心选择 $\mathbb{E}[\text{CPC}_i]$ 最低且置信度为中高（$C \ge 40\%$）的频道填满约 **80% 预算**（每个频道默认先排 1 次，强制分散风险，避免把 \$300 全押在 1 个号上）。
   - 剩余 **20% 预算**优先分配给 1～2 个“类目高度匹配、报价低廉但处于冷启动期（$C < 40\%$）”的新频道，并在界面上向广告主坦诚说明：**「💡 已为您配置 85% 稳健主力频道 + 15% 潜力新号赛马预算，帮助您发掘低价黑马渠道」**。
4. **Step 4 投后一键优胜劣汰（结案报告复投引擎）**：
   - 投放满 24h 出具报告时，系统自动按实测 $\text{CPC}_{\text{actual}, i}$ 排序：
     - **🏆 红榜（胜出号）**：实测 $\text{CPC}_{\text{actual}, i} \le 0.8 \times \overline{\text{CPC}}_{\text{campaign}}$ 且无异常刷量信号的频道 $\rightarrow$ 推荐下期**保留并加倍排期**。
     - **⚠️ 黑榜（淘汰号）**：实测 $\text{CPC}_{\text{actual}, i} \ge 1.5 \times \overline{\text{CPC}}_{\text{campaign}}$ 或 0 点击的频道 $\rightarrow$ 推荐下期**暂停投放，将省下的预算平滑转移给红榜频道与下一批新候选频道**。
   - 这一逻辑不需要任何黑盒 AI，广告主一眼就能看懂为什么这么建议，从而心甘情愿点击 **`[采纳优化方案，一键复投]`**。
