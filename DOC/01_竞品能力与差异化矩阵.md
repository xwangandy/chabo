# 01｜竞品能力与差异化矩阵（任务 A & 调研项 1）

> **核查日期**：2026-11-05  
> **研究范围**：Telega.io、AdsGram.ai（区分同名站点 adsgram.store）、TGStat、Telegram Official Ads（官方广告平台）、Collaborator.pro、RichAds 等直接与间接竞品。  
> **证据分级定义**：  
> - **【官方确认】**：竞品官方文档、FAQ、API 文档或公开条款明确记载。  
> - **【公开演示/第三方评价】**：公开评测报告、营销指南、无需授权可见的前台页面确认。  
> - **【推测】**：根据行业通用技术原理或前台表现做出的合理推演。  
> - **【未知】**：需付费下单或登录竞品私有管理后台才能看到的内部逻辑，本文绝不虚构。

## 二、 竞品逐一深度拆解（流程、优劣势与证据）

### 1. Telega.io（插播在“频道担保交易”模式上的头号参考系）
* **重要来源**：
  - Telega.io 官方 FAQ 与帮助中心：https://telega.io/faq （核查日期：2026-11-05）
* **1) 广告主完整操作流程** 【官方确认】：
  1. 注册登录网页端 $\rightarrow$ 进入频道目录（Catalog），按分类（Crypto、IT、Marketing 等）、语言、订阅区间、ERR（互动率）、价格区间筛选频道，或直接选购平台打包好的折扣套餐（Ready-made Packages）。
  2. 将心仪频道加入购物车，选择广告格式（如 `1/24`、`2/48`、Native Post）和期望发布日期/时间段。
  3. 填写广告文案、上传图片/视频、填入目标链接（可选开启平台短链点击追踪）。
  4. 预充值冻结预算（支持银行卡、绑卡支付、加密货币 USDT 等）。
  5. 等待频道主接单并在约定时间窗口发布（由绑定在频道的机器人自动发帖或人工发帖后机器人核验）。
  6. 投后在后台查看发布链接、各小时浏览量增长、短链总点击与独立点击数；若频道主拒单或未按约履约，冻结款退回平台余额。
* **2) 频道主完整操作流程** 【官方确认】：
  1. 提交频道（需满足最低订阅与真实阅读门槛），验证管理员所有权并添加官方机器人以开启自动发布与统计。
  2. 设置各广告格式（`1/24`、`2/48` 等）刊例价与可排期时间。
  3. 收到订单通知后，在规定时限内选择“接受”或“拒绝”；接受后按排期自动或手动发出。
  4. 保持帖子在约定置顶期（如 1 小时）和保留期（如 24 小时）内不被删除。
  5. 订单核验完成后，扣除平台佣金（约 12.5%）后的净收益进入可提现余额（满 \$20 可提现，每周一、三、五处理，需邮件确认）。
* **3) 技术与商业弱点** 【公开演示/第三方评价 + 推断】：
  - **中文生态近乎空白**：以俄语、英语频道为主，中文优质垂类频道储备极少，且界面与客服不符合华人广告主（习惯 TG 私聊通知+极简网页、USDT/OTC 结算）的操作习惯。
  - **外链短链去重黑盒且易损转化**：Telega.io 的独立点击去重算法未公开【未知】，且普通 HTTP 短链在移动端跳出或跳回 `t.me` 时存在客户端弹窗损耗。
  - **刷量防御滞后**：虽然接入了部分 TGStat 浏览数据，但对于“买僵尸粉+买浏览量脚本”伪造高 ERR 的频道，在广告主真正花钱投出 0 点击之前很难提前识别。

### 2. AdsGram.ai（插播在“效果归因与转化回传”上的重要参考系）
* **重要来源**：
  - AdsGram 官网与开发者文档：https://adsgram.ai/ 、https://docs.adsgram.ai/ （核查日期：2026-11-05）
  - 同名混淆排雷说明：`adsgram.store`（https://docs.adsgram.store/service-status）系另一处于 Pilot 阶段的站点，切勿将二者混为一谈 【官方确认】。
* **1) 广告主与开发者流程** 【官方确认】：
  - **广告主**：创建 Campaign $\rightarrow$ 选择流量类型（Mini App 激励视频/插屏、Bot 广告、频道帖或 Telegram Ads 代理） $\rightarrow$ 选择计费目标（CPM、tCPC 或 tCPA） $\rightarrow$ 在落地页 URL 中配置 `{click_id}`、`{record_data}` 等追踪宏 $\rightarrow$ 充值 USDT 启动学习期（Learning Phase）与投放。
  - **流量主（Publisher）**：小程序或 Bot 开发者集成 AdsGram SDK / API 代码块，按实际展示/点击获得 USDT 分成。
* **2) 技术与商业弱点** 【官方确认 + 第三方评价】：
  - **流量心智偏低质（积分墙/小游戏效应）**：Mini App 激励广告的用户往往是为了领游戏金币而点广告，停留时间短、付费意愿远低于优质垂类内容频道的忠实读者。
  - **频道原生深度种草能力弱**：程序化统一尺寸的 Banner 无法替代大 V 频道里图文并茂、带有信任背书的原生定制插播。
  - **tCPA 学习期门槛高**：若广告主单次预算只有几十美金，根本喂不饱机器学习的冷启动样本量（通常要求几十个转化事件才能跑出稳定模型）。

### 3. TGStat & Telemetr.io（插播在“频道体检与防刷信号”上的参考系）
* **重要来源**：https://en.tgstat.com/analytics （核查日期：2026-11-05）
* **核心能力** 【官方确认】：通过大规模 MTProto 爬虫节点持续抓取全球公开频道的订阅数、单帖小时级浏览曲线、被转发次数、与其他频道的互推/引用关系（Citation Index）。
* **核心弱点** 【官方确认 + 推断】：
  - **有宽度无深度**：只能看到“表面浏览量”，完全看不到某条广告到底带来了多少次点击、多少个 Bot 启动、多少次成交。
  - **合规高危**：依赖庞大的非授权爬虫账号池，违反 Telegram 开发者条款 4.3 的风险极高，不适合插播在 V1 阶段模仿自建。

### 4. 官方 Telegram Ads（`ads.telegram.org`）
* **重要来源**：https://ads.telegram.org/getting-started 、https://ads.telegram.org/guidelines （核查日期：2026-11-05）
* **核心特征与局限** 【官方确认】：
  - 优点：0.1 TON 起拍、可指定任意 $\ge 1,000$ 人的公开频道强行插入底部赞助消息（无需该频道主同意，只要该频道未关闭广告）。
  - 致命局限：**160 字纯文本限制**（表现力极弱）、**严禁挂外部网页 URL**（电商独立站、外部 App 下载页完全无法直投）、审核极其严苛（禁祈使句、禁诸多垂类）。

## 三、 对 R1 / R2 报告中竞品判断的纠偏与审计

1. **纠正 R1 的过度悲观**：R1 认为“Telega.io 已做完频道市场和排期，AdsGram 已做完 tCPA，所以插播做平台没有壁垒”。
   - **事实纠偏**：Telega.io 做的是**俄/英泛流量超市**，既没有针对中文垂类做“站内活人探针验号”，也没有解决“报告页直接驱动下一次复投”的代投服务闭环；AdsGram 的 tCPA 核心在**小程序激励广告**而非频道原生大帖，且小预算客户根本跑不通它的机器学习冷启动。
2. **纠正 R2 的过度乐观**：R2 提出“用站内探针 + 同行水位线对比就能打败竞品”。
   - **事实纠偏**：在冷启动前 30 单内，平台根本没有足够多的同行业历史投放样本去计算有统计意义的“打败了 80% 同行”分位数！在样本不足时强行展示“同行分位”，属于伪科学误导。**冷启动期必须用「跨频道同场横评（同一场投 5 个号，直接对比这 5 个号的 CPC 高低）」代替「全行业历史分位」**。

## 四、 插播（ChaBo）可落地的差异化破局策略（学什么、避什么）

### 1. 坚决借鉴的成熟设计（不重复发明轮子）
1. **借鉴 Telega.io 的「在位时长标准化刊例（`1/24`、`2/48`）」与「观察期担保结算」**：现有 `ChaBo` 代码（`src/chabo/fulfillment.py`）已有 24 小时观察期确认收益机制，应明确将广告位耗时规则（置顶几小时、保留几小时不删）写进订单快照，避免口头扯皮。
2. **借鉴 Telega.io 的「Ready-made Packages（行业打包套餐）」**：新广告主面对几十个频道根本不会选，直接推出“AI 工具出海 5 频道联投测试包（\$199）”，转化率远高于让客户自己去列表里大海捞针。
3. **借鉴 AdsGram 的「`{click_id}` 轻量回调接口」**：不需要做复杂的 SDK，只需在短链跳转时支持把 `click_id` 作为 URL 参数传给广告主落地页（如 `https://merchant.com/?chabo_cid=xxx`），让有技术能力的广告主可以用一行 HTTP 请求回传注册/付款事件。

### 2. 坚决规避的竞品死胡同
1. **避开 TGStat 式的“全网无授权公开频道爬虫”**：开发维护成本极高且随时面临 Telegram 封号与法律追责，V1 只采已授权入驻频道数据。
2. **避开 AdsGram 式的“小样本伪智能 tCPA 竞价承诺”**：在没有几千次转化数据前，绝不向客户承诺按 CPA 结算或自动竞价，坚持**“按固定刊例/套餐收费 + 用脱水 CPC 数据帮客户下一轮优胜劣汰频道”**。
3. **避开 Collaborator.pro 式的“双向重度抽佣（充钱收 10%、提现再收 15%）”**：高达 25% 的综合摩擦会逼迫买卖双方在認識后跳过平台私下交易（跳单）。插播必须将综合抽佣控制在 **5%～10%**（甚至用“保留平台招商尾标免佣金”换取免费裂变流量），让走平台比私聊更划算、更省心。
